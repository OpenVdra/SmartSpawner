# ![](https://cdn.modrinth.com/data/aBVLHiAW/2ad201b237497093c4957095fa9f97bf61708ed1_96.webp){.plugin-icon} BentoBox

**Download:** [Modrinth](https://modrinth.com/plugin/bentobox)

SmartSpawner uses the standard BentoBox island flags.

| Action | Flag |
|---|---|
| Open menu | `CONTAINER` |
| Stack | `PLACE_BLOCKS` |
| Break | Not checked |

Breaking has no dedicated SmartSpawner flag. BentoBox's own built-in block-break protection already guards the spawner block, so a player who cannot break blocks on the island cannot break the spawner either.

## Configure flags

Adjust the flags per island through the island settings menu, or set the world default so the desired island rank can use spawners. If a location is not on any island, the world default for the flag applies.
