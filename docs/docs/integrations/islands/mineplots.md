# ![](/icons/integrations/mineplots.svg){.plugin-icon} minePlots

**Download:** [BuiltByBit](https://builtbybit.com/resources/mineplots.21646/)

Access is decided by plot access. A player may open, stack, or break a spawner only if they have access to the plot it sits on.

| Action | Requirement |
|---|---|
| Open menu | Plot access |
| Stack | Plot access |
| Break | Plot access |

Grant plot access through minePlots' own commands. Outside any plot, spawners are unrestricted.
