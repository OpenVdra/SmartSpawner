## Yêu Cầu

| Yêu cầu | Thông số |
|---------|----------|
| **Phiên bản Minecraft** | 1.21.6+ |
| **Phần mềm máy chủ** | Paper, Folia, Purpur hoặc fork tương thích |
| **Phiên bản Java** | Java 25+ |

## Cài Đặt

1. **Dừng hoàn toàn máy chủ**
2. Tải file `.jar` mới nhất
3. Đặt file vào thư mục `plugins/`
4. **Khởi động máy chủ**; không dùng `/reload`

Xem [Hướng dẫn cài đặt](/vi/docs/installation) để biết toàn bộ quy trình.
