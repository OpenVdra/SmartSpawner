# ![](/icons/integrations/mineplots.svg){.plugin-icon} minePlots

**Tải về:** [BuiltByBit](https://builtbybit.com/resources/mineplots.21646/)

Quyền truy cập được quyết định bởi quyền plot. Người chơi chỉ có thể mở, xếp chồng hoặc phá spawner nếu họ có quyền trên plot chứa spawner.

| Thao tác | Yêu cầu |
|---|---|
| Mở menu | Có quyền plot |
| Xếp chồng | Có quyền plot |
| Phá | Có quyền plot |

Cấp quyền plot qua lệnh riêng của minePlots. Bên ngoài mọi plot, spawner không bị giới hạn.
